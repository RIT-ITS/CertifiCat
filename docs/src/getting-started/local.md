# Local Evaluation Stack

The included Compose example starts CertifiCat, its background task worker,
MariaDB, and Redis. It uses a local certificate authority and development-only
credentials.

## Prerequisites

- Docker with the Compose plugin
- Git
- CertBot (or any modern ACME client)

## Walkthrough

### Start CertifiCat

Clone the repository, enter it, and start the example stack:

``` bash
git clone https://github.com/RIT-ITS/CertifiCat.git
cd CertifiCat
docker compose -f examples/simple.yaml up --detach
```

Open [http://localhost:8000](http://localhost:8000) and sign in with the example
credentials:

```text title="login credentials"
Username: admin
Password: admin
```

!!! warning
    The simple example contains known credentials and an insecure local
    certificate authority. Use it only for local development and testing.

### Create an Account

Navigate to [http://localhost:8000/accounts/](http://localhost:8000/accounts/) and create a new account. Follow the instructions to register your client with the newly-created credentials.

### Request a test certificate

With Certbot installed, request a certificate from the local ACME directory:

``` bash 
sudo certbot certonly \
  --standalone \
  --server http://localhost:8000/directory \
  --domain host.docker.internal
```

!!! note
    This example uses HTTP-01 validation. The client running the preceding command must be able to bind to port 80.

### View your certificate

After your client successfully exits, navigate to [http://localhost:8000/certificates/](http://localhost:8000/certificates/). You'll see your new certificate as well as any others generated by clients using CertifiCat.

### Stop the stack

``` bash
docker compose -f examples/simple.yaml down
```

Add `--volumes` to the command if you also want to remove the example database volume.
